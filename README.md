# 🚀 Full Stack Developer — Career Restart

This repository documents my journey to becoming a **Full Stack Software Developer**, starting from scratch and rebuilding my skills step by step.

## 🎯 Goal
To become a confident, job-ready Full Stack Developer, capable of building and deploying real applications end-to-end — frontend, backend, mobile, and basic AI integration.

## 🗺️ Learning Path
I'm following a structured, phase-based path — backend first, then frontend, then mobile, then DevOps — so each phase builds on real, working knowledge from the one before it:

1. **JavaScript Fundamentals** — promises, async/await, try/catch, array/object methods
2. **Node.js + Express** — server basics, routing, middleware, REST APIs
3. **MongoDB + Mongoose** — database design, CRUD, schema modeling
4. **First Backend Project** — a complete REST API, deployed
5. **React** — components, state, hooks, connecting to a real backend
6. **Next.js** — Server/Client Components, routing, full-stack deployment
7. **React Native + Expo** — mobile app development, shared backend
8. **Docker** — containerizing real projects
9. **Backend/Server Management** — deployment, auth, scaling, monitoring
10. **Python for AI** *(parallel track)* — Python basics → NumPy/Pandas → AI API integration
